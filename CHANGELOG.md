## [1.0.0] - 2024-10-18

### 🚀 Features

- Complete CLI with interactive prompts for release, feature, and deploy commands
- Multi-platform deployment support (Cloudflare Workers, Vercel, Netlify, AWS, custom)
- Automated changelog generation from conventional commits
- GitHub integration with PR creation and auto-merge capabilities
- NPM publishing automation with registry support
- Comprehensive configuration system with environment overrides
- TypeScript support with strict mode compliance
- Full test framework setup with Vitest
- Comprehensive documentation and examples

### ⚙️ Configuration

- Support for `.go-workflow.config.js`, JSON files, and package.json configuration
- Environment variable overrides for CI/CD integration
- Flexible deployment target configuration
- Customizable changelog sections and commit type filtering

### 🧪 Testing

- Vitest test framework setup
- Mock utilities for Git, GitHub, file system operations
- Test coverage configuration
- Unit tests for core modules

### 📚 Documentation

- Complete README with usage examples
- Configuration examples for different project types
- Deployment target setup guides
- API documentation for programmatic usage

### 🔧 Development

- TypeScript strict mode configuration
- ESLint with TypeScript rules
- Modern build system with TSUP
- Automated pre-publish checks
